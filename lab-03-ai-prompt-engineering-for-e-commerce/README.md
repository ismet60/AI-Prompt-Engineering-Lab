# Lab 03 — AI Prompt Engineering in E-Commerce

![E--Commerce](https://img.shields.io/badge/Focus-E--Commerce-1D9E75?style=flat-square)

Explore how clearer instructions, business context, and output formats can improve AI responses about personalization, inventory management, and customer privacy.

---

## What You Will Learn

| Skill | Purpose |
| --- | --- |
| Establish a baseline | Observe how an AI responds to a broad question. |
| Compare prompt variations | Examine changes in tone, detail, and practical usefulness. |
| Add context and constraints | Guide a response toward a specific business scenario. |
| Evaluate AI output | Review actionability, relevance, and practicality. |
| Consider privacy | Ask balanced questions about customer data and safeguards. |

## Prerequisites

- Access to a conversational AI tool
- A browser or application for running prompts and recording observations
- No Python installation is required for this exercise

## Method

1. Run a broad prompt to establish a baseline.
2. Try variations in separate conversations to reduce carryover from earlier messages.
3. Add a role, context, task, output format, and constraints.
4. Compare the responses for actionability, relevance, and practicality.
5. Independently verify claims before using recommendations for a real business.

## Task 1 — Establish a Baseline

A broad personalization question from the assessment was:

> How can AI be utilized to personalize shopping experiences for customers on an e-commerce platform?

The recorded response gave a general overview. The assessment observed that it lacked priorities, costs, and a specific business context.

## Task 2 — Refine the Prompt

The assessment used a five-part framework: **role, context, task, format, and constraints**. This adapted example keeps the structure while using a generic scenario:

```text
Role: You are an AI personalization adviser for a small online business.
Context: The business receives about 1,000 website visitors each month and uses a chatbot and online lead forms.
Task: Recommend five practical ways to personalize the buying journey, prioritized by ease and expected impact.
Format: Use a table with technique, how it works, example tool, cost level, and expected benefit. End with a short starting recommendation.
Constraints: Use plain language, stay under 300 words, minimize personal data, and identify privacy considerations for human review.
```

The assessment reported that a structured prompt produced a more focused table and starting recommendation than the broad question. Results can vary between runs.

## Task 3 — Optimize an Inventory Prompt

The assessment refined an inventory question for a hypothetical small clothing retailer with about 300 products, 1,000 monthly orders, and a limited budget. It requested four strategies, a consistent table, and a 30-day action plan. The added context and constraints made the reported response easier to evaluate for that scenario.

Any example savings percentages, cost estimates, or product suggestions are prompts or AI-generated claims—not verified results. Check them against current sources and the business's own data.

## Task 4 — Examine Ethical Considerations

Review customer privacy, data minimization, transparency, consent, and security when proposing personalization. Ask for both benefits and risks, rather than assuming that an AI tool is fully trustworthy.

AI-generated guidance does not establish regulatory compliance. Relevant legal and privacy requirements should be independently reviewed by qualified people.

## Task 5 — Evaluate the Responses

| Criterion | Question |
| --- | --- |
| Actionable | Does the response offer clear next steps? |
| Relevant | Does it address the business scenario and question? |
| Practical | Are its tools, cost assumptions, and steps suitable for the business? |

## Key Takeaway

The assessment found that a defined role, realistic context, a requested format, and clear constraints helped produce more focused responses than simple rewording alone. Test outputs critically: wording can influence a response, but it does not guarantee accuracy or compliance.
